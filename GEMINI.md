# Chocolates Tronador Web: Antigravity Guidelines

This repository follows the **Taste Skill** design engineering standards. Antigravity must apply these guidelines whenever working with frontend, layout, HTML, CSS, React, or UI components.

## Available Workspace Skills:
- **`taste-skill`**: Core anti-slop frontend framework ([.agents/skills/taste-skill/SKILL.md](.agents/skills/taste-skill/SKILL.md)).
- **`redesign-skill`**: UI auditing and visual upgrade runbook ([.agents/skills/redesign-skill/SKILL.md](.agents/skills/redesign-skill/SKILL.md)).
- **`output-skill`**: Full output enforcement, bans partial code or placeholder comments ([.agents/skills/output-skill/SKILL.md](.agents/skills/output-skill/SKILL.md)).
- **`soft-skill`**: High-end luxury aesthetics, nested double-bezel cards, and fluid motion ([.agents/skills/soft-skill/SKILL.md](.agents/skills/soft-skill/SKILL.md)).

## UI Directives:
- Always declare the **Design Read** and set the **Three Dials** (`DESIGN_VARIANCE`, `MOTION_INTENSITY`, `VISUAL_DENSITY`) with intention.
- Never use AI-slop tropes (Inter default, purple neon glow, centered hero with dark mesh, 3 identical cards).
- Use warm, rich, tactile tones fitting an artisanal chocolate brand.
- Zero em-dashes (`—`).
- Always run the Pre-Flight Checklist before marking a UI task as done.
